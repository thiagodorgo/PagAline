# PagAline - Gestão de Contas a Pagar

## Overview
PagAline is a mobile-first, Android-style PWA for managing accounts payable (contas a pagar) in Brazilian Portuguese. Full-stack application with PostgreSQL database, Express backend, and React frontend.

## Architecture
- **Frontend**: React + Vite + TailwindCSS + shadcn/ui
- **Backend**: Express.js with TypeScript
- **Database**: PostgreSQL with Drizzle ORM
- **State Management**: Zustand (API-backed, no persist)
- **Routing**: wouter
- **PWA**: vite-plugin-pwa with Workbox service worker

## Key Design Decisions
- Language: All UI in Portuguese (pt-BR)
- Font: Outfit (Google Fonts)
- Primary color: Purple (#7c3aed / --primary: 250 84% 54%)
- Mobile-first: max-w-md centered layout with fixed bottom nav
- Categories are `{id, name}` objects from DB
- Dates are ISO strings from DB — use `parseISO()` / `toDate()` helper before date-fns operations
- Settings uses fixed `id='default'` row; fields: userName, userPlan, customPhotoUrl, monthlyGoal

## Database Schema
- `bills`: id, description, amount, dueDate, category, status, notes, imageUrl, paidDate, createdAt
- `categories`: id, name
- `settings`: id (default='default'), userName, userPlan, customPhotoUrl, monthlyGoal

## API Routes (all prefixed with `/api`)
- GET/POST `/api/bills`, GET/PATCH/DELETE `/api/bills/:id`
- POST `/api/bills/:id/pay`, POST `/api/bills/pay-multiple`
- GET/POST `/api/categories`, DELETE `/api/categories/:id`
- GET/PATCH `/api/settings`
- POST `/api/reset`

## PWA Configuration
- manifest.webmanifest generated by vite-plugin-pwa
- Service worker with Workbox: precaches static assets, NetworkFirst for API calls, CacheFirst for Google Fonts
- Icons: icon-192.png and icon-512.png in client/public/
- Installable on Android Chrome via "Add to Home Screen"

## Important Files
- `shared/schema.ts` — Drizzle schema + Zod types
- `server/routes.ts` — Express API routes
- `server/storage.ts` — DatabaseStorage class with seedDefaults()
- `client/src/lib/store.ts` — Zustand store with API calls
- `client/src/pages/` — Home, Bills, Scan, Reports, Settings
- `client/src/components/layout/MobileLayout.tsx` — Bottom nav layout
- `vite.config.ts` — Vite config with PWA plugin
